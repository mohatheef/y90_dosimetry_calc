Clinical Guidance & TheraSpheres Notes

  • Target Mass: Liver tissue density is assumed at 1.05 g/cm³. Target Mass = (Volume × 1.05) / 1000 kg.
  • Lung Safety: Absorbed lung dose must not exceed 30 Gy for a single infusion or 50 Gy cumulative lifetime dose.
  • Sequential Lobar Infusion: For bi-lobar disease, calculate separate prescriptions per lobe separated by 4 to 6 weeks.

Clinical Guidance Protocol (EANM/CIRSE)

LSF < 10%: Normal range. Proceed with planned activity.
LSF 10% – 15%: Moderate shunting. Reduce activity by 20%.
LSF 15% – 20%: High shunting. Reduce activity by 40% and ensure lung dose < 30 Gy.
LSF > 20%: Contraindicated. High risk of fatal radiation pneumonitis.

Mathematical Formulations & Algorithmic Specifications

Standardized equations based on international consensus guidelines and official product monographs.

1. Partition Multi-Compartment Model

The Partition Model accounts for differential microsphere trapping in hypervascular tumors versus normal liver parenchyma and lungs.

Tumor Involvement (%): TI = [ Volume_tumor / (Volume_tumor + Volume_normal) ] × 100
Tumor-to-Normal Ratio: TNR = ( TotalCounts_tumor / Mass_tumor ) / ( TotalCounts_normal / Mass_normal )
Absorbed Dose: Dose_tissue = ( 49,670 × Activity_tissue ) / Mass_tissue [Gy]
Activity based on Normal Liver Limit (D_NL): Activity = [ D_NL × ( TNR × Mass_tumor + Mass_normal ) ] / [ 49,670 × ( 1 - LSF ) ]
Activity based on Desired Tumor Dose (D_T): Activity = [ D_T × ( TNR × Mass_tumor + Mass_normal ) ] / [ 49,670 × TNR × ( 1 - LSF ) ]
Activity based on Lung Limit (D_L): Activity = [ D_L × Mass_lung ] / [ 49,670 × LSF ]

2. MIRD Single-Compartment Model (TheraSpheres)

Assumes uniform spatial distribution of microspheres throughout the targeted anatomical volume.

Target Mass (kg): Mass_target = Volume_target × 1.05 / 1000
Calculated Activity (GBq): Activity = ( Dose_target × Mass_target ) / [ 50 × ( 1 - LSF ) ]
Absorbed Lung Dose (Gy): Dose_lung = Activity × LSF × 50 / Mass_lung

3. BSA Model (SIR-Spheres)

Empirical relationship matching patient body habitus to safe liver dose tolerance.

Body Surface Area: BSA [m²] = 0.20247 × ( Height [m] ^ 0.725 ) × ( Weight [kg] ^ 0.425 )
Target Activity (GBq): Activity = [ BSA - 0.2 + ( Volume_tumor / Volume_target ) ] × ( Volume_target / Volume_liver )
LSF Reduction: LSF < 10% (0%), 10-15% (20% reduction), 15-20% (40% reduction), >20% (Contraindicated).
